## 🛠️ Estructura del Proyecto

* `/back0901`: Contiene el servidor Node.js y la API REST.
* `/front0901`: Contiene la interfaz de usuario desarrollada en React.
* `/1. Base de datos`: Contiene los scripts SQL para la creación de las tablas y relaciones.

## 💻 Instalación y Configuración

1.  **Configurar la Base de Datos:**
    Importa el archivo localizado en `1. Base de datos/ff.sql` en tu gestor de base de datos.

2.  **Configurar el Backend:**
    ```bash
    cd back0901
    npm install
    npm start
    ```

3.  **Configurar el Frontend:**
    ```bash
    cd front0901
    npm install
    npm run dev
    ```
